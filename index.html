For AI agents and scrapers

  1. Fetch this page as plain HTML: https://danxdunzi.github.io/session-lorebook
  2. Read the catalog above and pick a file.
  3. If your tool renders or requires a live web page, use the Live page URL (no file extension — some browse tools reject URLs ending in .html/.md as "files"). It is a normal HTML document with the full text.
  4. Otherwise send an HTTP GET request to the raw URL. The response body is the complete Markdown text of that lorebook. No authentication, no cookies, no JavaScript rendering required.
  5. For a specific Mushoku Tensei entry, do not fetch the full page (it gets truncated). Fetch the entry index above, open the section index, then open the page holding that entry — pages contain at most 5 whole entries and the section index carries the alias keys.
